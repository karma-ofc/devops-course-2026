# Подготовка к контрольной работе

## Когда выбрать rebase, а когда merge?

Rebase использую для локальной ветки, чтобы получить линейную историю перед публикацией. Merge использую для объединения уже опубликованных веток без переписывания их истории.

## Что произойдет при rebase публичной ветки?

Изменятся хеши коммитов. Коллегам придется синхронизировать свои ветки, поэтому rebase публичной ветки может вызвать конфликты и проблемы.

## Зачем нужен multi-remote?

Multi-remote позволяет отправлять один проект в разные репозитории. Например, в GitHub для основной разработки и в GitLab как резервную копию или зеркало.
